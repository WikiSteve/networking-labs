## Summary

This reusable Azure architecture lecture deck moves from broad platform geography and governance into compute, networking, storage, identity, and security services, with a few Azure Learn sandbox tasks mixed in. It starts with Azure tooling in Cloud Shell, including PowerShell, Bash, `az interactive`, and sandbox exploration of mounted storage and subscription details. It then explains Azure's physical and logical layout through regions, sovereign regions, availability zones, region pairs, edge zones, geographies, points of presence, and Azure Orbital. From there it covers governance structure with accounts, subscriptions, management groups, and resource groups, then shifts into compute choices, networking, storage, identity, and security.

## Key Details

- Includes practical Azure Learn sandbox tasks using Cloud Shell to inspect the Linux environment, mounted storage, and subscription details.
- Explains Azure geography concepts including regions, sovereign regions, availability zones, region pairs, edge zones, geographies, and points of presence.
- Uses examples such as U.S. government regions, China via 21Vianet, the Microsoft global datacenter map, and Azure Orbital.
- Covers governance structure with accounts, subscriptions, resource groups, and management groups.
- Explains compute options such as virtual machines, VM scale sets, availability sets, Azure Virtual Desktop, containers, Azure Functions, and App Service.
- Covers virtual networking topics including point-to-site VPN, site-to-site VPN, ExpressRoute, network security groups, network virtual appliances, custom routes, and VPN gateway models.
- Includes high-availability networking ideas such as active/standby and active/active VPN gateways, BGP, ExpressRoute failover, and zone redundancy.
- Teaches Azure Storage architecture including Blob Storage, Data Lake Storage Gen2, Azure Files, Queue Storage, Table Storage, and managed disks.
- Breaks down storage resiliency options including LRS, ZRS, GRS, and GZRS plus blob access tiers.
- Includes migration and hybrid topics such as Azure Data Box and Azure File Sync.
- Compares Azure AD with on-prem Active Directory and covers Azure AD Connect, passwordless authentication, Conditional Access, external identities, and RBAC.
- Ends with Zero Trust, defense-in-depth, Microsoft Defender style security functions, and homework on the Microsoft Learn Azure architecture and services path.
