## Summary

This reusable introductory lecture deck covers core cloud computing concepts using Microsoft Azure as the framing platform. It starts by grounding cloud in the reality of datacentres and co-location facilities, including physical infrastructure concerns like remote KVM access, uptime, cooling, and telecommunications interconnection, then transitions into the three main cloud service models: IaaS, PaaS, and SaaS. The deck explains each model through practical scenarios such as lift-and-shift migration, dev and test replication, managed development frameworks, analytics platforms, productivity tools, and email services. It also emphasizes shared responsibility, private and hybrid cloud thinking, Azure SLAs, scalability, governance, cost optimization, and the main Azure management methods such as portal, CLI, APIs, and PowerShell.

## Key Details

- Opens with datacentre and co-location concepts so cloud is framed as someone else's infrastructure rather than magic.
- Uses 151 Front Street West and TorIX as a real-world Canadian carrier-hotel and exchange example.
- Introduces IaaS as the model that shifts datacentre capital and operations to the provider.
- Explains PaaS as a managed application platform with built-in scalability, high availability, and multi-tenancy.
- Presents SaaS through examples such as Office 365, Google Docs, email, messaging, and business apps.
- Includes the shared-responsibility reminder that customers still own their data, identities, and authorized devices.
- Covers private cloud and points toward hybrid cloud integration.
- Explains Azure SLA and high-availability targets using concrete uptime percentages and downtime examples.
- Defines scalability as both vertical scaling and horizontal scaling, including auto-scaling ideas.
- Pulls in Azure Well-Architected Framework ideas around right-sizing, cost management, budgets, alerts, governance templates, and compliance auditing.
- Lists Azure management options as web portal, command-line interface, APIs, and PowerShell.
- Ends with homework on the Microsoft Azure Fundamentals cloud-concepts learning path.
