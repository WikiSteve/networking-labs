## Summary

This reusable survey lecture deck covers core AWS services through the same broad cloud building blocks used in introductory cloud courses: compute, storage, databases, and networking. The compute section covers EC2 instance families and workload fit, burstable versus non-burstable instances, Elastic Beanstalk as a PaaS model, Auto Scaling with policy-driven scale actions, Lambda as event-driven FaaS, container services such as ECS, EKS, ECR, and Fargate, and Elastic Load Balancing with ALB, NLB, and CLB. The storage section compares AWS services to Azure equivalents, including S3, EBS, EFS, Glacier, Storage Gateway, and FSx, while also explaining storage models such as object, block, file, archival, and hybrid storage. The later sections survey managed database services and core AWS networking concepts such as VPC, Route 53, Direct Connect, VPN, Anycast, geolocation routing, latency-based routing, and CloudFront edge locations.

## Key Details

- Covers AWS compute services including EC2, Elastic Beanstalk, Auto Scaling, Lambda, ECS, EKS, ECR, and Fargate.
- Breaks down EC2 instance families by workload and explicitly compares burstable versus non-burstable CPU models.
- Explains Elastic Beanstalk as PaaS rather than SaaS or serverless.
- Details Auto Scaling concepts such as scaling policies, health checks, scheduled scaling, and ELB integration.
- Compares Lambda and Fargate, emphasizing short-lived event-driven functions versus longer-lived container workloads.
- Includes Elastic Load Balancing fundamentals and differences among ALB, NLB, and CLB.
- Maps AWS storage services to Azure counterparts, including S3, EBS, EFS, Glacier, Storage Gateway, and FSx.
- Explains Storage Gateway modes such as File Gateway, Volume Gateway, and Tape Gateway.
- Surveys managed database options including RDS, DynamoDB, Aurora, Redshift, DocumentDB, and Neptune.
- Covers underlying concepts such as relational versus NoSQL, document, graph, and data-warehouse models.
- Introduces VPC, Route 53, Direct Connect, AWS VPN, Anycast, geolocation DNS, latency-based routing, and CloudFront edge locations.
- Ends with practical submission guidance for AWS labs and review expectations.
