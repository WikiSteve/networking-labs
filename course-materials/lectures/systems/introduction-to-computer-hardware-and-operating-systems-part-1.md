## Summary

This reusable introductory lecture deck covers core computer hardware concepts and the relationship between hardware and the operating system. It focuses on the CPU, registers, combinational logic, cache hierarchy, DRAM, and long-term storage, using kitchen and pantry analogies to explain performance tiers and memory roles. The deck defines hardware, explains the CPU's responsibility for executing instructions, introduces clock speed and cores, then drills into registers, ALU behavior, cache levels, and cache hits versus misses. It then expands outward to DRAM as main memory, compares volatile memory to non-volatile storage, and contrasts HDDs and SSDs as long-term storage. It also includes course logistics and applied tasks such as downloading a Debian ISO, creating a bootable drive, forming groups, and preparing for a live hardware-identification evaluation.
