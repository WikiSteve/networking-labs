## Summary

This reusable submission template defines the three screenshot deliverables for a static routing lab. It does not teach the routing setup itself. Instead, it requires proof of router-to-host connectivity, Windows-based web and traceroute validation to an internal Debian web server, and a cross-group connection that traverses both groups' routers. Its purpose is to standardize what gets submitted and make the grading target explicit.

## Key Details

- The template requires three screenshots as the full submission package.
- Screenshot 1 must be taken from the router and prove IP configuration by pinging both the Windows computer and the Debian web server.
- The notes mention that the Windows firewall may need to be disabled for the ping proof.
- Screenshot 2 must be taken from the Windows computer and show the internal web server page plus a traceroute in the same screenshot.
- The internal website must include the learner's name somewhere on the page.
- Screenshot 3 requires connecting to another group's website from Windows and showing a traceroute path through both routers.
- The instructions explicitly allow both groups to submit the same screenshot for screenshot 3 only.
- The file is reusable as a generic assessment scaffold for the routing lab.
