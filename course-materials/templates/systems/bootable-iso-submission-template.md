## Summary

This reusable submission template defines the required proof for the bootable ISO lab. It does not teach the full procedure. Instead, it specifies the two screenshots students must submit: one showing Rufus being used to create the bootable Debian USB image, and one showing Debian successfully booted inside VMware Workstation from that USB media. It functions as an evidence checklist and submission shell for the lab.

## Key Details

- The deck is explicitly for the bootable ISO lab submission.
- It requires exactly two screenshots in the final submission.
- Screenshot 1 is Rufus image creation.
- Screenshot 2 is Debian booted in VMware Workstation.
- The file acts as a packaging guide for evidence, not as the instructional lab itself.
- It is reusable across offerings because it is generic and not tied to one learner.
- It pairs directly with the lab guide and enforces a consistent submission structure.
