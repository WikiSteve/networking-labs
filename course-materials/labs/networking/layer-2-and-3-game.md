## Summary

This reusable classroom activity turns Layer 2 and Layer 3 addressing into physical role-play games using fictional MAC addresses and street-style IP addresses. It contains two main activities: a packet relay race where participants act as network nodes passing a packet based on destination MAC and IP information, and an ARP role-play where one participant broadcasts a "who has this IP?" request and the matching participant replies with the corresponding MAC address. The goal is to make abstract networking concepts visible and memorable through movement, cards, and call-and-response rather than command-line tools.

## Key Details

- Uses themed fictional identifiers for both MAC and IP addresses to make the activity more memorable.
- The first activity is a simplified packet relay race using a simulated topology such as a circle, mesh, or line.
- Each participant is assigned both a MAC-style identifier and an IP-style identifier on cards.
- The packet carries source and destination MAC addresses plus source and destination IP addresses.
- The instructor acts as a DNS server to start the game and announces the destination IP.
- Each node reads the destination MAC aloud and waits for the matching node to respond before passing the packet on.
- The activity includes timing or racing variations for review or competition.
- The second activity is a simplified ARP role-play where one participant knows the receiver's IP but not the MAC.
- The matching participant replies with the MAC, modeling ARP request and ARP reply behavior.
- The file works well as an active-learning or review exercise for introductory networking topics.
