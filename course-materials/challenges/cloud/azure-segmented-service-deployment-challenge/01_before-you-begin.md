# Before You Begin

- Solo or pairs
- One Azure tenant per submission
- Due before the final quiz
- Use **password authentication** for this practical.
- Choose a **strong, unique password** for each VM.
- Do not reuse an old password. A VM with a public IP and a weak password can be compromised quickly.
- Use the same region for the resource group, VNet, and both VMs.
- Keep your screenshots as you work so you are not trying to recreate them at the end.

## Naming Rule

Use a unique first-name prefix for the named Azure resources you create so they are easy to identify during grading.

Use one student's first name consistently. If you are working in a pair, pick one partner's first name and use it everywhere.

Examples:

- resource group: `rg-steve-practical`
- VNet: `vnet-steve-practical`
- server VM: `vm-steve-server`
- client VM: `vm-steve-client`
- NSG: `nsg-steve-server-segment`

Keep the subnet names the same:

- `server-subnet`
- `client-subnet`
