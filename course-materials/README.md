# Course Materials

Tracked copy of curated course files and their corresponding notes.

Principles:

- Organize by subject first, not by original course folder.
- Keep lectures, labs, challenges, and templates separate.
- Preserve a note per source file with a direct source link.
- Keep the original ignored archive workspace separate from this tracked copy.

Top-level areas:

- `lectures/`
- `labs/`
- `challenges/`
- `templates/`
- `sources/`
