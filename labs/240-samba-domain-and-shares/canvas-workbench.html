Beginner Windows Permissions

Why can Bob read Workbench, but cannot save?

Network writes pass through two separate gates: the SMB Share gate and the NTFS folder gate. Both must allow saving.

✕

Save blocked by NTFS

SMB share allows Change, so Bob passes Gate 1, but NTFS Modify is OFF at Gate 2.

SMB share allows Change Gate 1 · Network share permission
ON
NTFS allows Modify Gate 2 · Folder security permission
OFF
Read is already allowed at both gates.

Simplified teaching model: Windows applies the most restrictive result of SMB Share and NTFS permissions. This demo assumes Bob already has Read access on both layers and no explicit Deny rules exist.
