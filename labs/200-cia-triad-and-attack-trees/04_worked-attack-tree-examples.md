# Worked Attack Tree Examples

Use these examples to understand how the tree should grow before you build your own.

## Example 1: Steal a lion

This example is intentionally a bit absurd, but it is memorable and it shows the mechanics of an attack tree clearly.

- [Watch: Attack tree example, how to steal a lion](https://www.youtube.com/watch?v=XamjLKpQ2OY)

### Core idea

Objective:

- steal a lion

High-level branches:

- get a lion from Africa
- get a lion from a zoo

The example then develops the zoo branch using:

- tools such as cutters, a truck, and a tranquilizer
- countermeasures such as cameras and guards
- attacker responses such as painting over a camera

The main point is not the scenario itself. The point is learning how to structure:

- alternatives
- dependencies
- countermeasures
- attacks against countermeasures

## Example 2: Open a locked door

This second example is more realistic and focuses on step dependencies and defender responses.

- [Watch: Attack tree example, opening a locked door](https://www.youtube.com/watch?v=b93NojnFhGE)

### Core idea

Objective:

- open a locked door

High-level branches:

- use brute force
- open the lock

The example then develops paths such as:

- reinforce the door with a solid core and deadbolt
- pick the lock
- get the key
  - steal it
  - copy it
  - return it

It also introduces countermeasures and responses:

- motion detector
- guard
- bribe the guard
- knock out the guard
- break the motion detector

## What you should copy from these examples

Your assignment is not to recreate these two trees. Instead, copy the structure:

- start with a clear objective
- split it into major options
- show which branches are alternatives and which are dependent
- include defenses where they matter
- include attacker responses where they matter
