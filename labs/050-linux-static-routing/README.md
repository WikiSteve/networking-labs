# Linux Static Routing

> **Before you start:** Download the [Static Routing Submission Template](./assets/Static%20routing%20SUBMISSION%20TEMPLATE.pptx). Add each required screenshot directly into this file as you complete the lab, then submit the completed template for grading.

## Goal
Configure static routes between Debian VMs and verify reachability to a partner’s tunnel address.

## Prereqs
Use VMware Workstation and your Debian VM backup. For partnered routing, find your assigned tunnel address in the provided spreadsheet and exchange your DHCP addresses with your partner.
